HTML Document Shell

Every HTML page starts with the same handful of required elements. Nothing on the page renders until these are in place.

Live Demo

A bare document shell has no visible content of its own — the demo box below is just the browser's default blank canvas.

(empty page)

Code

HTML
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Page</title>
</head>
<body>

</body>
</html>
The lang attribute, meta charset, and meta viewport aren’t visible on the page — but they’re required on every page you build this semester.
