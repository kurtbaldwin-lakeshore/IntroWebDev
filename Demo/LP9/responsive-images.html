Responsive Images

Without this rule, a large image can overflow its container and force a horizontal scrollbar on small screens. max-width: 100% keeps every image inside its parent.

Live Demo

Code

HTML
<img src="photo.jpg" alt="Description of photo">
style.css
img {
  max-width: 100%;
  height: auto;
}
