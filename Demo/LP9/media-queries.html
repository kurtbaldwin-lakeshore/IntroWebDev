Media Queries

A media query is a conditional block for CSS — the rules inside only apply when the screen matches the given width. Try resizing your browser window.

Live Demo

Resize the window — this box changes color under 500px

Code

HTML
<div class="banner">Resize the window</div>
style.css
.banner { background: #3A7CA5; }

@media (max-width: 500px) {
  .banner { background: #E0872A; }
}
