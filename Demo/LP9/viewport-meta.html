Viewport Meta Tag

Without this tag, mobile browsers pretend the screen is 980px wide and shrink the whole page to fit — tiny, unreadable text. This tag tells the browser to use the device’s actual width.

Live Demo

No visual demo — this tag’s effect only shows up on an actual phone-width viewport. Resize your browser narrow to see LP9’s media query topic in action instead.

Code

HTML
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
</head>
