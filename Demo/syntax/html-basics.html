HTML Syntax Basics

Every tag and pattern covered from LP1 through LP5 — the complete HTML toolkit before CSS is introduced.

Document Structure

Every page starts with this shell.

<!DOCTYPE html>

Must be the very first line of every HTML file.

<html lang="en">

Wraps the whole page; lang tells assistive tech what language to read in.

<head>

Holds meta info — not visible on the page itself.

<meta charset="UTF-8">

Sets the character encoding.

<meta name="viewport" ...>

Tells mobile browsers to use the real device width.

<title>

The text shown in the browser tab.

<body>

Everything visible on the page goes here.

Text & Headings

<h1> – <h3>

Heading levels. Exactly one h1 per page; h2/h3 nest underneath in order.

<p>

A paragraph of body text.

<strong>

Semantic emphasis (renders bold).

<em>

Semantic emphasis (renders italic).

<!-- comment -->

A note in the code that never renders on the page.

Lists

<ol> / <li>

Ordered (numbered) list, when sequence matters.

<ul> / <li>

Unordered (bulleted) list, when order doesn’t matter.

Images & Tables

<img src="" alt="">

Every image needs alt — descriptive text, or alt="" if purely decorative.

<table> / <caption>

A data table, named by its caption.

<thead> / <th>

The header row — th cells are announced differently than td by screen readers.

<tbody> / <tr> / <td>

The table body: rows and data cells.

Links

<a href="">

A link. href is where it points.

target="_blank" rel="noopener noreferrer"

Opens in a new tab, safely. Always use them together.

<a href="#section-id">

A fragment link — jumps to an id elsewhere on the same page.

<a href="mailto:...">

Opens the visitor’s email client.

Skip navigation link

The first focusable element in body, for keyboard users.

Forms

<input type="text/email/tel/number/date">

Common single-line input types.

<input type="radio">

Pick exactly one from a group — wrap the group in fieldset/legend.

<input type="checkbox">

Independent on/off — any number can be checked.

<select> / <optgroup>

A dropdown; optgroup labels categories within it.

<textarea>

A multi-line text box.

<label for="...">

for must match the input’s id exactly — required on every input.
