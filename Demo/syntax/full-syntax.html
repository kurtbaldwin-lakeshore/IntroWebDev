Full Syntax Reference

The complete picture: every HTML pattern from the first half of the course, plus semantic structure, selectors, properties, and responsive basics from LP6 through LP9.

Document Structure

Every page starts with this shell.

<!DOCTYPE html>

Must be the very first line of every HTML file.

<html lang="en">

Wraps the whole page; lang tells assistive tech what language to read in.

<head>

Holds meta info — not visible on the page itself.

<meta charset="UTF-8">

Sets the character encoding.

<meta name="viewport" ...>

Tells mobile browsers to use the real device width.

<title>

The text shown in the browser tab.

<body>

Everything visible on the page goes here.

Text & Headings

<h1> – <h3>

Heading levels. Exactly one h1 per page; h2/h3 nest underneath in order.

<p>

A paragraph of body text.

<strong>

Semantic emphasis (renders bold).

<em>

Semantic emphasis (renders italic).

<!-- comment -->

A note in the code that never renders on the page.

Lists

<ol> / <li>

Ordered (numbered) list, when sequence matters.

<ul> / <li>

Unordered (bulleted) list, when order doesn’t matter.

Images & Tables

<img src="" alt="">

Every image needs alt — descriptive text, or alt="" if purely decorative.

<table> / <caption>

A data table, named by its caption.

<thead> / <th>

The header row — th cells are announced differently than td by screen readers.

<tbody> / <tr> / <td>

The table body: rows and data cells.

Links

<a href="">

A link. href is where it points.

target="_blank" rel="noopener noreferrer"

Opens in a new tab, safely. Always use them together.

<a href="#section-id">

A fragment link — jumps to an id elsewhere on the same page.

<a href="mailto:...">

Opens the visitor’s email client.

Skip navigation link

The first focusable element in body, for keyboard users.

Forms

<input type="text/email/tel/number/date">

Common single-line input types.

<input type="radio">

Pick exactly one from a group — wrap the group in fieldset/legend.

<input type="checkbox">

Independent on/off — any number can be checked.

<select> / <optgroup>

A dropdown; optgroup labels categories within it.

<textarea>

A multi-line text box.

<label for="...">

for must match the input’s id exactly — required on every input.

Semantic Structure (LP4+)

Replaces generic divs wherever a more specific element fits.

<header> / <nav> / <main> / <footer>

The top-level landmarks of a page.

<section> / <article> / <aside>

Content groupings within main.

CSS Selectors (LP7+)

p { }

Element selector — targets every instance of that tag.

.name { }

Class selector — reusable on any number of elements.

#name { }

ID selector — must be unique, one per page.

:hover / :focus-visible / :link / :visited / :active

Pseudo-classes — target a state, not just a tag.

[aria-current="page"] { }

Attribute selector — targets the current nav link.

Common Properties (LP6–LP8)

color / background-color

Text color and fill color.

font-size / font-weight / font-style / font-family

Type size and appearance.

text-align / text-decoration / line-height

Alignment, underlines, vertical spacing.

border / border-radius

border: width style color; — border-radius rounds corners.

padding / margin

Space inside the border / space outside the border.

display: block / inline / inline-block / flex / none

How an element participates in layout.

--custom-property / var(--name)

Define a value once in :root, reuse it everywhere.

background-image: url() / linear-gradient()

An image, a gradient, or both layered together.

External CSS & Responsive (LP7, LP9)

<link rel="stylesheet" href="css/style.css">

Connects an HTML page to an external stylesheet.

@media (max-width: 500px) { }

Applies rules only when the screen matches the condition.

img { max-width: 100%; height: auto; }

Keeps images from overflowing their container.
