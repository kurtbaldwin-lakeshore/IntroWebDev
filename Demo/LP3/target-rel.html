target & rel

target="_blank" opens a link in a new tab. Whenever you use it, pair it with rel="noopener noreferrer" so the new tab can’t control the original page.

Live Demo

Check the Wisconsin DNR site (opens in a new tab).

Code

HTML
<a href="https://dnr.wisconsin.gov" target="_blank" rel="noopener noreferrer">
  Wisconsin DNR site
</a>
