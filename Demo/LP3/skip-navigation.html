Skip Navigation Links

A skip link is the very first focusable element in the body. It lets keyboard users jump straight past the header and nav to the main content.

Live Demo

Skip to main content
(visually hidden until a keyboard user tabs to it, on a real site)

Code

HTML
<body>
  <a href="#main">Skip to main content</a>
  <header>...</header>
  <main id="main">...</main>
</body>
