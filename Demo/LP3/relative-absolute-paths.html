Relative vs. Absolute Paths

A relative path is read starting from the current file’s location. An absolute path always starts from the site’s root — or from https:// for a full external URL.

Live Demo

Paths don’t have a visual difference — the difference is in what breaks and when you move files. See the code for both patterns.

Code

HTML
<!-- Relative: from this file’s folder -->
<a href="about.html">About</a>
<a href="../index.html">Home</a>

<!-- Absolute: always from the site root -->
<a href="/about.html">About</a>

<!-- Full external URL -->
<a href="https://example.com">External site</a>
