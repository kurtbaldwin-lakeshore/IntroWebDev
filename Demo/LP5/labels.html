Labels

A label’s for attribute must match its input’s id exactly. This connection lets screen readers announce the label, and lets users click the label to focus the input.

Live Demo

Code

HTML
<label for="email">Email Address</label>
<input id="email" type="email">
If the for and id don’t match exactly, the label isn’t connected — even though it may look fine visually.
