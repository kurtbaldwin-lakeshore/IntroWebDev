Radio Buttons & fieldset/legend

Radio buttons let a user pick exactly one option from a group. Wrapping the group in fieldset and legend gives it one shared accessible name.

Live Demo

Ticket Type

Code

HTML
<fieldset>
  <legend>Ticket Type</legend>
  <input type="radio" id="single" name="ticket">
  <label for="single">Single Day</label>
  <input type="radio" id="weekend" name="ticket">
  <label for="weekend">Weekend Pass</label>
</fieldset>
