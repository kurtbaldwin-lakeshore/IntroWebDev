Dropdown & optgroup

A select collapses many options into one control. optgroup organizes long option lists into labeled categories.

Live Demo

Code

HTML
<select>
  <optgroup label="Wisconsin">
    <option>Madison</option>
    <option>Milwaukee</option>
  </optgroup>
  <optgroup label="Other">
    <option>Chicago</option>
  </optgroup>
</select>
