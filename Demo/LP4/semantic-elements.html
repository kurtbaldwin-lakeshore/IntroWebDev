Semantic Elements

Semantic elements describe what content is, not just how it looks. A screen reader user can jump straight to “navigation” or “main content” because these tags say what they contain.

Code

HTML
<header>...</header>
<nav>...</nav>
<main>
  <section>
    <article>...</article>
  </section>
  <aside>...</aside>
</main>
<footer>...</footer>
Before LP4, this same layout was built with generic <div> elements. Semantic tags replace divs wherever a more specific element fits.
