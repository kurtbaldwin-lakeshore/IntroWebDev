Custom Properties

A custom property is declared once, usually in :root, and reused anywhere with var(). Change the one declaration and every rule using it updates.

Live Demo

All three boxes reference the same --color-primary variable.

Code

HTML
<div class="swatch"></div>
<div class="swatch"></div>
<div class="swatch"></div>
style.css
:root {
  --color-primary: #3A7CA5;
}

.swatch {
  background: var(--color-primary);
}
