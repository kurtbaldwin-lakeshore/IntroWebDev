Google Fonts

A link to Google Fonts loads a custom typeface. The CSS font-family list always includes a fallback in case the web font fails to load.

Live Demo

This heading uses a loaded web font, with serif as its fallback.

Code

HTML
<head>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link href="https://fonts.googleapis.com/css2?family=Playfair+Display" rel="stylesheet">
</head>
style.css
h1 {
  font-family: 'Playfair Display', Georgia, serif;
}
