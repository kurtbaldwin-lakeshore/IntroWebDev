Navigation Styling

A real navigation bar combines Flexbox layout with pseudo-class states and aria-current to mark the active page.

Live Demo

HomeAboutContact

Code

HTML
<nav>
  <a href="index.html" aria-current="page">Home</a>
  <a href="about.html">About</a>
  <a href="contact.html">Contact</a>
</nav>
style.css
nav { display: flex; gap: 4px; }
nav a { padding: 8px 14px; border-radius: 6px; }
nav a[aria-current="page"] { background: var(--color-primary); color: #fff; }
