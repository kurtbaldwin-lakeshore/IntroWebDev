Typographic Scale

A typographic scale is a small, consistent set of font sizes used throughout a site, instead of picking a new size for every heading by feel.

Live Demo

Code

HTML
<h1>Page Title</h1>
<h2>Section</h2>
<h3>Subsection</h3>
<p>Body text</p>
style.css
h1 { font-size: 2.5rem; }
h2 { font-size: 1.8rem; }
h3 { font-size: 1.3rem; }
p  { font-size: 1rem; }
