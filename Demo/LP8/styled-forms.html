Styled Forms

Form controls don’t inherit page fonts by default. A form reset applies font-family: inherit and a consistent border to every input, select, and textarea.

Live Demo

Code

HTML
<input type="text" placeholder="Styled input">
style.css
input, select, textarea {
  font-family: inherit;
  font-size: 1rem;
  padding: 8px 10px;
  border: 1px solid #DED9CC;
  border-radius: 6px;
}
