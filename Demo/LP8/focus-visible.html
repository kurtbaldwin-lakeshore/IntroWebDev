:focus-visible

:focus-visible shows a focus indicator only when the browser thinks the user is navigating by keyboard — not on every mouse click.

Live Demo

Code

HTML
<button>Tab to me</button>
style.css
button:focus-visible {
  outline: 3px solid #E0872A;
  outline-offset: 2px;
}
