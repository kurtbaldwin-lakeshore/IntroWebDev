background-image

background-image accepts a url(), a gradient, or both layered together — a gradient listed first sits on top of the image beneath it.

Live Demo

linear-gradient background-image

Code

HTML
<div class="banner"></div>
style.css
.banner {
  background-image: linear-gradient(135deg, #3A7CA5, #E0872A);
}
