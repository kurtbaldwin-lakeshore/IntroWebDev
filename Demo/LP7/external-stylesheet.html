External Stylesheet

A link tag in the head connects an HTML page to an external CSS file. One stylesheet can style every page that links to it.

Live Demo

This is the moment every inline style attribute gets deleted and replaced by rules living in one shared file.

Code

HTML
<head>
  <link rel="stylesheet" href="css/style.css">
</head>
style.css
/* All the rules that used to be
   inline style="" attributes now
   live here instead */
p { color: #5B5F78; }
