margin

margin adds space outside an element’s border, between it and its neighbors. margin: 0 auto centers a block element that has a max-width.

Live Demo

margin: 0 auto;

Code

HTML
<div class="centered">margin: 0 auto;</div>
style.css
.centered {
  max-width: 200px;
  margin: 0 auto;
}
