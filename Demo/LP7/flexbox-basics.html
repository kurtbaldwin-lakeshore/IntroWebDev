Flexbox Basics

Setting display: flex on a parent turns its direct children into flex items, arranged in a row by default with even gaps.

Live Demo

1
2
3

Code

HTML
<nav class="flex-row">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</nav>
style.css
.flex-row {
  display: flex;
  gap: 10px;
}
