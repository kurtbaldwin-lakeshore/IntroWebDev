Class & ID Selectors

A class (.name) can be reused on any number of elements. An id (#name) must be unique — used on exactly one element per page.

Live Demo

.highlight class — reusable

#hero id — used once

Code

HTML
<p class="highlight">Reusable on many elements</p>
<p id="hero">Used once per page</p>
style.css
.highlight {
  background: #FCEFD9;
}

#hero {
  background: #1B1F3B;
  color: #fff;
}
