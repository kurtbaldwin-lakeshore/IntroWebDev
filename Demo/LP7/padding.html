padding

padding adds space between an element’s content and its border. The shorthand accepts one, two, or four values.

Live Demo

padding: 20px;

Code

HTML
<div class="card">padding: 20px;</div>
style.css
.card {
  padding: 20px;
  background: #F1EFE8;
}
