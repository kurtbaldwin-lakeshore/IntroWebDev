Specificity

When two rules target the same element, the more specific selector wins — regardless of which one appears later in the file. IDs beat classes; classes beat element selectors.

Live Demo

This text is green — the #id rule wins over .class and p.

Code

HTML
<p id="demo-spec" class="demo-spec-class">This text is green.</p>
style.css
p                { color: teal; }      /* 0,0,0,1 */
.demo-spec-class { color: coral; }     /* 0,0,1,0 — wins over p */
#demo-spec        { color: #3D8361; }  /* 0,1,0,0 — wins over both */
