Unordered Lists (Nested)

Use ul when items don’t have a required order. A ul can nest inside a li to create a sub-list.

Live Demo

  • Fruits
    • Apples
    • Bananas
  • Vegetables

Code

HTML
<ul>
  <li>Fruits
    <ul>
      <li>Apples</li>
      <li>Bananas</li>
    </ul>
  </li>
  <li>Vegetables</li>
</ul>
