Data Tables

Tables are for tabular data — not layout. A caption names the table, and th marks header cells so screen readers can announce them.

Live Demo

Code

HTML
<table>
  <caption>Weekly Hours</caption>
  <thead>
    <tr><th>Day</th><th>Hours</th></tr>
  </thead>
  <tbody>
    <tr><td>Monday</td><td>4</td></tr>
    <tr><td>Tuesday</td><td>6</td></tr>
  </tbody>
</table>
