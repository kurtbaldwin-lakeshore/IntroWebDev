Images & Alt Text

Every img needs an alt attribute. If the image conveys information, describe it. If it’s purely decorative, use an empty alt so screen readers skip it.

Live Demo

stand-in for <img>

alt=“A red barn at sunset” describes what the image shows.

Code

HTML
<img src="barn.jpg" alt="A red barn at sunset">

<!-- Purely decorative image -->
<img src="swirl-divider.png" alt="">
