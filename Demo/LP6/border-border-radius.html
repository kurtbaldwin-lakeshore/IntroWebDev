border & border-radius

border is a shorthand for three values in order: width, style, and color. border-radius rounds the corners.

Live Demo

border: 3px solid #3A7CA5; border-radius: 10px;

Code

HTML
<div style="border: 3px solid #3A7CA5; border-radius: 10px; padding: 16px;">
  Rounded, bordered box
</div>
Inline Style
border: 3px solid #3A7CA5;
border-radius: 10px;
