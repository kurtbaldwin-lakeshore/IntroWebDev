font-weight, font-style & font-family

Three separate properties that all shape a font’s appearance: weight controls thickness, style controls italics, and family sets the typeface.

Live Demo

font-weight: 700

font-style: italic

font-family: Georgia, serif

Code

HTML
<p style="font-weight: 700;">Bold text</p>
<p style="font-style: italic;">Italic text</p>
<p style="font-family: Georgia, serif;">Serif text</p>
Inline Style
font-weight: 700;
font-style: italic;
font-family: Georgia, serif;
