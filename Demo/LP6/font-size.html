font-size

font-size controls text size. rem is relative to the root font size and is the right default choice for most text.

Live Demo

This text is 1.5rem.

Code

HTML
<p style="font-size: 1.5rem;">This text is 1.5rem.</p>
Inline Style
font-size: 1.5rem;
